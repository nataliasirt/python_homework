1. XPath selection - the hardest part was figuring out how to select the correct links using XPath. It also had a <strong> tag inside them with the name of the risk. So I made an XPath that looks for links that have /Top10/A and _2021- in their href (link address). This helped me pick only the links I needed.
2. Getting just the risk title: the actual risk name is inside a <strong> tag inside each link. I used XPath to get only that tag’s text. To be safe, I added a try-except block in case the <strong> tag was missing — in that case, the code just grabs the link’s full text instead.
3. Making sure the page is loaded: instead of using time.sleep() (which waits a fixed time), I used WebDriverWait. This waits only until the risk elements are actually on the page. It’s more reliable and works better if the internet is slow or the page takes longer to load.
4. Running Chrome without opening a Window (headless): I ran the script in headless mode so it doesn’t open a browser window. But to make it work smoothly, I added a few Chrome options like --no-sandbox and --disable-dev-shm-usage to avoid common errors.
